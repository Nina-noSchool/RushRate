# ANALYSIS-RL-20261121 — 限流器（令牌桶）实弹验收与开关对照

## 一、背景

2026-11-21 批次落地三件入口防护（`90cc283` 之后）：

1. **令牌桶限流器**：`@RateLimit` 注解 + `rate_limit_token_bucket.lua`（惰性补充、Redis TIME 服务器时钟、clamp 60s 防跳变），IP/券双维度接入（验证码 10/5、seckill-plus 50/20），fail-open（Redis 异常放行不阻断业务），总开关 `seckill.rate-limit.token-bucket.enabled`
2. **售罄短路**：首次 Lua 返"库存不足"后本地标记 TTL（5min，`seckill.sold-out.mark-ttl-ms`）内直接拒绝，洪峰下售罄请求不打 Redis
3. **令牌前置授权**：开抢前领资格令牌（`POST /voucher-order/seckill-token/{id}`），抢购经 `X-Seckill-Token` 头携带，Lua 一次性消费（GET 比对后 DEL），开关 `seckill.access-token.enabled`（默认关）

三层防线分工：**滑窗限流挡用户级刷（既有）、令牌桶挡接口/IP 水位、售罄短路挡无效流量、令牌前置挡资格外流量**——语义互不重叠。

## 二、验收结果

### 1. 令牌桶单接口实弹（15 连打，验证码接口 IP 维度）

| 指标 | 值 |
|---|---|
| 通过 / 拒绝 | **10 / 5**（= 桶容量 10 精确生效） |
| 拒绝响应 | `验证码请求过于频繁，请稍后重试`（注解 message 透传） |
| `hmdp_ratelimit_rejected_total` | 5.0 |
| Redis 桶状态 | `tokens=0.97`（打空后恒速回填可视化——令牌桶"突发容忍"语义证据） |

### 2. 洪峰开关对照（500 请求 / 30 并发 / 验证码接口 IP 维度）

| | 轮 1：限流**开** | 轮 2：限流**关** |
|---|---|---|
| 通过 | **19** | **500** |
| 拒绝 | **481** | **0** |
| `hmdp_ratelimit_rejected_total` | 481.0（精确=业务拒绝数） | 0.0 |
| 耗时 | 2s | 2s |

理论放行 = 桶容量 10 + 2s × 5/s ≈ 20，实测 19（浮点惰性补充边界）——**算法语义与指标双双精确**。

### 3. 售罄短路（券 20，库存清零）

| 步骤 | 结果 |
|---|---|
| 带有效令牌第 1 抢 | Lua 返 1 → `库存不足`（并标记售罄） |
| 无令牌第 2 抢 | **`库存不足，已售罄`**——本地短路命中（售罄检查在令牌 gate 之前），不打 Redis |
| 短路口日志 | `sold-out short-circuit hit` 计数 = 1 |

### 4. 令牌前置授权

| 步骤 | 结果 |
|---|---|
| 无令牌抢购 | `请先获取抢购资格`（库存 Lua 不执行） |
| 领取令牌 | UUID 返回 + Redis SET（TTL 10min） |
| 带令牌抢购 | success + 订单号（正常扣减） |
| 同令牌复用 | 再次拒绝（Lua GET 比对后 DEL，一次性消费） |
